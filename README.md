# Marico Cafe 来場者サイト

GitHub Pagesで配信する静的サイトです。`index.html`の各ゲーム紹介のタイトル下に、認証不要の公開API `GET /v1/status` を取得します。

## 接続先

現在は `https://shikosai-api.sg-tera.workers.dev/v1/status` に接続しています。本番DBにはゲームID 0〜7の8件が登録されています。

API接続先は`index.html`の`#game`にある`data-api-url`で指定します。公開一覧の取得に認証IDは不要です。公開HTMLに認証IDを入れないでください。

ゲーム紹介の `data-game-id` とAPIの `gameId` を対応させ、タイトルの下に「空き／利用中」と利用中の終了予定を表示します。名前・紹介文・人数・公式リンクは静的HTMLで管理します。現在の8件のカードには本番DBと同じID 0〜7を設定しています。ID未設定・APIに存在しないIDは「未確認」です。

## 更新と失敗時の動作

- 初回表示時、非表示から復帰した時、ブラウザの戻る操作でページが復元された時に取得します。定期取得は行わず、重複取得を防ぎます。
- 10秒でタイムアウトします。失敗直後の自動再試行はしません。
- 失敗時は前回の一覧と最終取得成功時刻を保持します。初回失敗は「未確認」と表示します。
- 終了予定は日本時間の目安として表示します。予定超過で自動的に空きへ変更しません。
- 状態は `textContent` で挿入します。

## 検証

Node.js 20以上で `node --test tests/congestion.test.cjs` を実行できます。追加パッケージは不要です。実際の画面スクリプトを使い、取得成功、初回・途中失敗、不正応答、空配列、タイムアウト、重複防止、非表示・復帰を検証します。

ブラウザではローカルHTTPサーバーで表示し、API接続とスマホ幅でのレイアウトを確認してください。デプロイは既存のGitHub Actionsが `main` へのpush時に実行します。
